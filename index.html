Client–Proxy–Web Server Berhasil Diakses

Halaman ini dikirim dari Web Server melalui Proxy Server. Sistem ini dibangun menggunakan socket programming Python dengan mekanisme forwarding, caching, serta pengujian jaringan.

Proxy Port

8080

Web Port

8000

UDP QoS

9000

Alur Sistem

1. Client Mengirim request HTTP ke proxy server.
2. Proxy Server Mengecek cache HIT/MISS dan meneruskan request.
3. Web Server Mengirim response HTML kepada proxy.
4. Response Proxy mengirim hasil akhir kembali ke client.
